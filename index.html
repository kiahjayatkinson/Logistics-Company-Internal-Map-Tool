JetMap — Route & Toll Calculator
Demo Build  ·  v2.0  ·  2026

JetMap replaces the manual Google Maps + spreadsheet workflow with a single live tool. Currently in production at a single depot, with national rollout planned. Enter any route to instantly receive country rates, real-time ETA, and automatic toll detection — all powered by the Google Routes API and calibrated to the company's rate card.

Zone Lookup
Search any Victorian suburb to confirm whether it falls inside or outside the country pricing boundary, with live map pin placement.
Rate Calculator
Up to 5 stops. Live routing calculates exact distance, ETA, and rates across all vehicle classes for both General and Express service.
Toll Detection
Automatically identifies EastLink and CityLink usage per route. Charge codes (TEA, TEB, TEC, TED, TEM, TLM) applied to 1T and 2T vehicles. Truck toll charges (TLE) calculated separately for 4T–12T.
Toll-Inclusive Totals
Toggle the rate table to show base rate + toll total across all vehicle classes, from light vehicles through to trucks. Staggered animation keeps the table clean until you need it.
Map Controls
Toggle the Country Rate Border via the header. Custom borders and manager tools accessible via the ⚙ buttons. Light and dark mode supported. Click ⓘ at any time to reopen this panel.
